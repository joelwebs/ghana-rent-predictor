
# Ghana Rent Price Predictor

A Machine Learning project that predicts estimated rental
prices of residential properties in Ghana using property
characteristics and location data.

## Project Objectives

- Analyse Ghanaian rental property data.
- Identify factors influencing rental prices.
- Develop regression models for rent prediction.
- Compare models using appropriate evaluation metrics.
- Build a reusable prediction system.
- Deploy the model for public use.

## Machine Learning Techniques

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- XGBoost Regressor
